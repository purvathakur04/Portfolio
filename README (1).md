# Responsive Personal Portfolio Website

A mobile-friendly portfolio showcasing skills, projects and contact details.

**Live demo:** https://your-username.github.io/portfolio/

## Features
- Mobile-first responsive layout (CSS Grid + Flexbox, media queries)
- Accessible structure: semantic HTML, skip link, ARIA labels, keyboard focus styles
- Dark / light theme toggle (saved in localStorage)
- Hamburger navigation for small screens
- Contact form with client-side validation

## Tech Stack
HTML5 · CSS3 · JavaScript (vanilla)

## Run Locally
1. Clone the repo: `git clone https://github.com/your-username/portfolio.git`
2. Open the folder in VS Code
3. Open `index.html` (or use the Live Server extension)
